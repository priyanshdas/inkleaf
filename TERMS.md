## 6. Changes InkLeaf PDF makes to your computer

Besides its own folder, InkLeaf PDF changes only these, and only for your user
account:

- **When it's installed** (the Windows installer): it registers itself as
  an app that can open PDFs, and adds its own thumbnail maker and previewer
  so File Explorer can show the first page of each PDF and preview every
  page. Uninstalling removes them.
  The Microsoft Store version declares the same in its package.
- **When you switch it on in Settings:** an entry so InkLeaf PDF starts when
  you sign in, and InkLeaf PDF's entries in File Explorer's right-click menu
  (Windows installer only; on by default, and off again in Settings).
  Switching a setting off removes its entry; uninstalling removes them all.
- **When InkLeaf PDF is your default PDF app:** it makes sure File Explorer
  uses InkLeaf PDF's thumbnails and previewer for PDFs.

Choosing the app that opens PDFs is always up to you: InkLeaf PDF only opens
the system's own settings for you to make that choice.
