Windows 10 and 11

Microsoft Store Installer (.exe) Portable, no install

The Store version installs without any security warning. The installer from GitHub may show a SmartScreen message: click More info, then Run anyway.

Linux

For this computer
Flatpak .deb .rpm AppImage

The Flatpak works on any distribution and keeps itself up to date: open it with your software centre, or run flatpak install --user https://priyanshdas.github.io/inkleaf/flatpak/inkleaf-pdf.flatpakref

Or use the .deb on Ubuntu, Debian or Mint, the .rpm on Fedora or openSUSE, and the AppImage anywhere else. On ARM: .deb or AppImage.
