Get a file

Someone sent you a PDF with an Inkleaf pickup code. It’s encrypted, and only that code can unlock it. It’s unlocked here in your browser, so the code never leaves this page.

Downloading uses up the code: after that, nobody can pick the file up again. Files nobody picks up are deleted after 7 days.

Have Inkleaf? Open it and choose Tools › Receive a File instead. If the sender locked the file to your computer, open the downloaded PDF in Inkleaf on that computer.
