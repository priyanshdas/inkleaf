Who makes it

I’m Priyansh. I’m a chef, and I write code in my spare time. I made InkLeaf PDF because every PDF editor I tried wanted a subscription, an account, or my files on their server, and most of the free ones couldn’t really change the text at all.

Plenty of free tools are good at one job: Xournal++ for writing on a PDF, PDF Arranger for pages, LibreOffice Draw for changing text (though the layout often shifts). I couldn’t find one free app that really replaces the words in the file and also signs, fills forms, cleans up scans and handles pages, offline, on my computer and my phone. If one of those tools already does what you need, it’s a fine choice.

It’s licensed under the GPL, so it will stay free and you can read, change and share every line of it. If something breaks or feels awkward, open an issue. Fixes to translations from people who speak the language are especially welcome.

If InkLeaf PDF saves you some time, you can buy me a coffee. It’s never required.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows builds are made by GitHub Actions straight from the public source code, and signed only after a maintainer approves the release. Nothing built on anyone’s own computer is signed.
